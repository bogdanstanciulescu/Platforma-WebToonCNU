# Platforma WebToonCNU
WebtoonCNU este o platformă web creată pentru concursul de bandă desenată digitală. Scopul ei este de a oferi un mediu modern, ușor de folosit, unde elevii pot publica lucrările lor, profesorii le pot evalua, iar publicul le poate descoperi și aprecia. Platforma integrează componente de web design, programare și baze de date.
